## 2. 엘리베이터 피치 & 차별점 (P0)

> Vampire Survivors의 자동 사격, Time Wasters의 컴포넌트 빌드, Battleship의 선박 조작감을 결합한 10분 로그라이트. 

세 레퍼런스에서 무엇을 가져왔는가:

- **Vampire Survivors**: 자동 사격, 레벨업 3택 강화, 시간 기반 위협 곡선.
- **Time Wasters**: 부품을 모아 자기 함을 조립하는 빌드 다양성.
- **Battleship(전투함)**: 선체 관성과 선회 — "정밀 회피"가 아니라 "궤적 예측"으로 살아남는 감각, 그리고 미니맵 레이더.

### 핵심 차별점 — 드롭 경쟁 시스템

네임드 적이 죽으면 장착하고 있던 컴포넌트 하나가 **부위 표기 채로 필드에 떨어진다**. 이 드롭은 일정 시간 후 바다 밑으로 가라앉으며 사라진다. 그동안 **플레이어와 주변 네임드가 동일 규칙으로 흡수 경쟁**한다. 늦으면 적이 더 강해진다.

- 그래서 이 게임은 단순한 픽업 게임이 아니라 **시간/공간/우선순위 경쟁** 게임이다.

## 4. 코어 루프 (P0)

### 30초 루프 (즉시 체감)

1. W 홀드로 항해, A/D로 선회.
2. 시야 안에 들어온 일반 몹을 자동 사격으로 처치.
3. EXP 젬 흡수 → 게이지 채움.
4. 미니맵으로 네임드/드롭/보스 위치 확인.

### 5분 루프 (중간 의사결정)

1. 네임드 등장 → 접근 또는 회피 판단.
2. 처치 시 드롭 발생 → **다른 네임드보다 먼저 도달시 강화**
3. 빈 슬롯이면 자동 장착 / 같은 부위면 레벨업 / 다른 부위·슬롯 가득이면 교체 파워업.

### 10분 루프 (세션 종결)

1. (경과시간 ≥ ❓) AND (네임드 처치 수 ≥ ❓) → 보스 스폰.
2. 보스 처치 → 스테이지 클리어 + 결과 화면.
3. 또는 HP 0 → 결과 화면.

### 메타 루프

- **v1.0 OUT**. v1.0+에 함장/배/시작 무기 선택 등을 도입 검토.

## 5. 핵심 메커닉 (P0)

### 5.1 선박 이동 (관성 + 선회)

- **선박은 월드 공간을 직접 이동한다.** 맵을 움직이거나 플로팅 오리진을 쓰지 않는다 — 1런 ≈ 10분·저속 항해라 float 정밀도 문제가 발생하지 않는다. 카메라는 선박을 추적한다(§8). 적·드롭·투사체는 모두 월드 좌표를 가진다.
- **W / Space**로 가속, **뗌 시 점진 감속**. 즉시 정지하지 않는다.
- **A/D** 또는 **←/→**로 선회. **회전 자체에도 관성 적용**.
- 항상 전방으로만 진행 — 후진 없음.
- **S / Left Control**로 전용 브레이크 — 자연 감속보다 빠르게 감속하되 **즉시 정지가 아니며**, 속도 0에서 멈춰 후진으로 넘어가지 않는다. 브레이크 강도: `❓W1 확정`.
- 가속/감속 곡선, 최대 속도, 회전 반경: `❓플레이테스트 확정`.

### 5.2 자동 사격 (Vampire Survivors식)

- 슬롯에 장착된 컴포넌트가 각자의 쿨다운/타게팅 규칙으로 자동 발사.
- 발사 방향은 컴포넌트 타입에 따라 다름 — 예: 주포=전방, 부포=측면, 어뢰=후방.
- 타입별 발사 규칙·사거리: `❓W1 확정`.

### 5.3 적 스폰 & 웨이브

- 시간 기반 일반 몹 + 주기/조건 기반 네임드 등장.
- 카메라 가시 영역 밖 링에서 동적 스폰.
- **이탈 처리는 등급별로 다르다**: 일반 몹 = 컬 반경 밖 → 풀 반환 / 네임드 = leash, 회피 가능(§5.5) / 보스 = leash 없음, 캐치업 추격(§5.6).
- 등장 비율/곡선: `❓플레이테스트 확정`.

**투사체 도배 회피 원칙**: **일반 몹은 투사체를 쏘지 않는다.** 일반 몹 공격은 접촉 또는 즉발(0-distance) 데미지로 처리하여 동시 투사체 수 폭증을 구조적으로 차단한다. 투사체 패턴은 네임드/보스에만 적용한다.

### 5.3.1 일반 몬스터 (3종)

| # | 종류 | 행동 | 공격 | 특이사항 |
|---|---|---|---|---|
| 1 | **나룻배** | 플레이어 직진 추격 | **접촉 데미지** | 가장 흔한 잡몹. 밀집 압박용. |
| 2 | **소형 배** | 추격 → 사거리 진입 시 정지 → 공격 | **즉발 데미지** — 쏘는 모션·이펙트만 표현, 실제로는 플레이어 객체에 접근해 `OnDamaged` 호출 | "사거리 유지"가 회피의 핵심. 거리 의사결정 유도. 일반 몹은 Rigidbody 미사용, `transform` 직접 조작이라 물리 기반 자연 감속 없음. |
| 3 | **잠수함** | 잠수(무적·무해) → 이동 → 출수 → 1회 공격 → 재잠수 | 출수 시에만 소형 배와 동일(즉발) | **드물게 등장**. 잠수 중 시인성 보조 — 그림자 등 간접 표시(`❓W1 확정`). |

- 종별 등장 확률·EXP 보상·HP·데미지: `❓플레이테스트 확정`.
- 네임드/보스의 공격(투사체 패턴): `❓W2 확정`.

### 5.3.2 부하 테스트 (W1 P0)

투사체 도배 리스크 외에도 동시 적/이펙트/드롭 수가 60fps 임계를 넘을 수 있다. W1 종료 전 다음 임계 수치를 도출한다.

- **동시 일반 적 수** @ 60fps 지속
- **동시 투사체 수** (네임드/보스) @ 60fps 지속
- **동시 드롭 아이템 수** @ 60fps 지속
- **동시 VFX 수** (침몰 연출 다중 발생 시) @ 60fps 지속

도출된 임계는 스폰 매니저 상한·풀 사이즈 설계의 기준이 된다. 도구는 Unity Profiler(GC alloc·Draw call·스크립트 비용 점검) 사용.

### 5.4 EXP / 레벨업 (패시브 트랙)

- 일반 몹 처치 → EXP 젬 → 흡수 반경 내 자동 흡인.
- 레벨업 시 **일시정지 + 3택 강화창**(뱀서식). 강화 풀 후보:
    - 공격속도, 데미지, 사거리
    - 최대 HP, HP 재생
    - 이동 가속/회전 속도
    - 경험치 흡수 반경
    - 컴포넌트 슬롯 추가 (검토)
- EXP 곡선: `❓W1 확정`.

### 5.5 네임드 시스템 (드롭 트랙) — 핵심 차별화

- **네임드 = 컴포넌트를 장착한 적 함.** 일반 몹보다 강하고, 사격 패턴이 차별화.
- **고유 컴포넌트**: 네임드는 스폰 시 랜덤한 고유 컴포넌트 1개를 장착하고 등장한다. 처치 시 **이 고유 컴포넌트가 부위 표기 채로 필드에 드롭**(UI에 부위 아이콘 노출). 미리 식별한 부위 = 처치 시 보장되는 전리품.
- **부위 인지**: 플레이어는 네임드의 부위를 **화면뷰에서 직접 보고** 판단한다 — 미니맵은 부위를 알려주지 않는다(§6.2). 화면 내 표시 방식(머리 위 부위 아이콘 vs 배 모델 외형)은 `❓UI/아트 작업 시 확정`.
- **선택적 루팅**: 필요 없는 부위의 네임드는 싸우지 않고 회피할 수 있다(아래 이탈 처리). 회피 = "위험 회피 ↔ 드롭 포기" 트레이드오프. 단 보스 트리거가 네임드 처치 수를 요구하므로(§5.6) 전부 회피할 수는 없다.
- 드롭은 일정 **타이머**(`❓W1 확정`) 동안 상주, 종료 시 **바다 밑으로 침몰 연출**과 함께 소멸. 드롭은 거리 컬링하지 않고 타이머로만 소멸한다.
- **경쟁 흡수 규칙**: 드롭 반경 내 플레이어 또는 네임드가 도달 시 흡수.
    - 흡수 우선순위·접근 의지: `❓W1 확정` (단순 거리 vs BT 가중치).
- 네임드의 흡수 → 해당 컴포넌트 장착 또는 레벨업. **즉시 강해짐**. 플레이어에 명확한 시각/사운드 피드백 필요.
- **이탈 처리 (leash)**: 네임드가 **leash 반경** 밖으로 벗어나면 디스폰한다 — 처치가 아니므로 드롭이 없다(= 회피 성공). leash 반경은 **미니맵 반경보다 바깥**으로 둔다: 미니맵에서 사라진 뒤에도 한동안 살아 추격하므로, 잠깐 벗어났다 돌아오면 재교전이 된다. leash 반경 값: `❓플레이테스트 확정` — SO 수치로 분리해 핫스왑.

### 5.6 보스 (스테이지 클리어)

- **트리거**: `(경과시간 ≥ X분) AND (네임드 처치 수 ≥ Y)`. X/Y는 `❓플레이테스트 확정`.
- **이탈 불가**: 보스는 leash가 없다. 플레이어 최대 속도보다 빠른 캐치업 속도로 추격해 간격이 항상 좁혀지므로 따돌릴 수 없다. 화면 밖에서는 미니맵 방향 화살표로 추적(§6.2). 런은 보스 처치 또는 플레이어 사망(§6.3)으로만 종료. 캐치업 속도: `❓플레이테스트 확정`.
- 등장 연출 + 화면 알림 + 미니맵 마커.
- 보스 패턴 단계: `❓W2 확정`.
- 처치 시 클리어 화면(시간/킬/장착 빌드 표시).

### 5.7 피해 / 사망

- HP는 단일 값. 피격 시 무적시간(i-frame, `❓W1 확정`).
- 사망 시 **퍼마덱스**: 함장/배/컴포넌트 모두 리셋. 즉시 결과 화면.
- 부활 아이템: **v1.0 OUT**.

## 6. 시스템 상세 (P0)

### 6.1 슬롯 & 컴포넌트

- **타입별 슬롯**: 주포 / 부포 / 어뢰 / 방어 / 유틸 등.
    - 정확한 카테고리 목록과 슬롯 개수: `❓W1 확정` (후보 슬롯 수: 4~6).
- **흡수 규칙**:
    - 빈 슬롯이면 자동 장착.
    - 같은 부위 보유 → 자동 레벨업 (Lv 상한 `❓W1 확정`).
    - 같은 부위 슬롯이 가득이고 다른 부위 → **드롭 접촉 시 일시정지 + 교체/유지 선택창**.
- 레벨업으로 얻는 변화: 공격력/속도/탄 수/특수 효과 — `❓W2 확정`.

### 6.2 미니맵 (배틀쉽 레이더 컨셉)

- 플레이어 중심 원형 레이더. 화면 우상단 또는 좌상단(`❓W1 확정`).
- 표시:
    - 일반 적 (작은 점)
    - 네임드 (강조 아이콘 — **부위는 표시하지 않음**; 부위 파악은 화면뷰에서, §5.5)
    - 보스 (전용 마커, 방향 화살표)
    - 드롭 아이템 (부위 아이콘 + 잔여 타이머 시각화)
    - 카메라 뷰포트 (옵션, `❓W1 확정`)
- 표시 범위/줌: `❓W1 프로토 후 확정` (네임드 leash 반경은 이 범위보다 바깥, §5.5).

### 6.3 승리 / 패배 조건

- **승리**: 보스 처치 → 스테이지 클리어.
- **패배**: HP 0 → 퍼마덱스 재시작.

### 6.4 플레이어 입력 (PC, Input System)

- **전진**: W **홀드 가속** / 뗌 시 감속.
- **브레이크**: S 또는 Left Control — 자연 감속보다 빠른 감속(후진 아님).
- **선회**: A/D 또는 ←/→.
- **일시정지**: Esc (잠정).
- **사격**: 자동, 수동 입력 없음.
- 게임패드/모바일 매핑: Action map만 정의해두고 실제 구현은 `v1.0 OUT`(우선순위 낮음).

### 6.5 UI 화면 구성 (v1.0 스코프)

- **HUD**: HP 바, EXP 바, 경과 시간, 슬롯 현황(부위 아이콘 + 레벨), 미니맵.
- **레벨업 선택창**: 일시정지 + 3택 카드.
- **드롭 교체 파워업**: 슬롯 가득 시 일시정지 + 현재 vs 신규 스탯 비교.
- **메인 메뉴**: 시작 / 종료.
- **일시정지 메뉴**: 계속 / 종료.
- **결과 화면**: 클리어/사망 분기, 시간·킬·최종 빌드 표시.

## 8. 아트 & 사운드 방향 (P1)

- **아트 스타일**: 로우폴리 3D.
- **컬러 팔레트**: 바다(블루 톤) vs 배(화이트/크림) 대비. 이펙트는 채도 높여 가독성 확보.
- **카메라**: 쿼터뷰 45° 고정, 플레이어 추적. 회전 없음.
- **레퍼런스 이미지/링크**: 없음 (`❓확인 필요`).
- **사운드 톤**: 유료 에셋 검토 중 — `❓W2 확정`. 항해 BGM + 전투 BGM 분리 검토.
- **UI 톤**: 깔끔, 게임 몰입 우선. 미니맵·HUD는 반투명 배경 + 고대비 아이콘.
- **핵심 VFX 후보**:
    - 드롭 소멸 시 **침몰 연출** (수면 아래로 가라앉음)
    - 네임드 흡수 시 강조 (적이 강해지는 시각 피드백)
    - 보스 등장 컷인
    - 피격 화면 흔들림 / 적색 비네트

## 9. 기술 스코프 & 제약 (P0)

- **Unity 패키지**: URP, Input System, TextMeshPro.

- **에셋 출처**: 자작 + 유료 에셋. 유료 에셋은 별도 폴더에 보관, 라이선스 추적.
